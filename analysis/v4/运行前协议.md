# v4 核心方案判定协议

日期：2026-10-26。此文件在本轮程序运行前写入。此前250款样本均参与过分析，本轮是冻结规则后的统一内部验证，不称全新确认集。新结果写入results/v4，保留v3.1文件及验收结果。

## 本轮先完成的决策

1. Q1主线只用化学输入。固定三专家：多输出ET、独立目标ET、分位数变换PLS8；风格均值只作独立对照。复用既有15个外层划分，外层训练集内再作2折风格分层以产生专家训练用OOF预测，所有预处理在各自子折拟合。
2. L1为三专家等权；另保留现有双ET等权作为强基线。L2分numeric/categorical两组求单纯形MAE最小权重，另作逐属性LP候选。LP目标不含额外正则，称全局最优仅针对给定内层预测矩阵上的凸权重问题。
3. 采纳L2须相对三专家L1及双ET基线均MAE改善至少1%、修正近似区间下界>0，且宏平均R²不低于两者。分组先于逐属性；逐属性若不能在同样规则下超过分组，保留分组。均不满足则使用先前已有三项指标改善证据的双ET等权。以上区间不作多重比较校正，不作为独立确认。
4. L3动态门控及PSO本轮不作为冻结阻塞项。后续只允许共享少量动态系数，比较等评估预算的PSO、Nelder–Mead及随机搜索；未经验证不写成有效改进。

## Q3判别器

- 固定Tripel对其余风格的二分类：训练折中位数插补、StandardScaler、PCA10、L2逻辑回归C=1、class_weight=balanced。阈值固定0.5，不在外层测试集调阈值；输出称判别得分，不称校准概率。
- 使用同一15个真实样本外层划分；每次250款OOF指标后对5次重复平均。只有平均AUROC>=0.80、balanced accuracy>=0.75、Tripel召回>=0.70、Pils/Lager误判Tripel率<=0.20同时满足，才启用为v4主要风格判据。否则保留为探索性诊断，不改写成“已确认有效”。
- 报告逐次指标、混淆计数及有限样本不确定性。分类器不能独立保证分布保真、工艺可行或缺陷感受。

固定PCA10逻辑回归未通过门槛后，追加一次有界内部选模对照：候选限定为原PCA10逻辑回归、无PCA的L2逻辑回归C=0.1、等先验自动收缩LDA、320棵树/leaf=3/max_features=0.7的平衡Extra Trees分类器。在每个外层训练集内2折按真实风格分层，用内层合并预测的balanced accuracy选择；相同时按上述顺序取简单者。外层启用门槛保持不变。此追加是模型开发，非独立确认；若仍失败不继续扩大分类器搜索。

## Q3条件OT

- 在与v3.1相同共同G空间拟合相同Ledoit–Wolf风格高斯。四项缺陷坐标固定为源测量值的潜在表示，分别构造源与目标的条件高斯，在其余指标上做OT；返回原坐标时直接保留四项已观测源值。
- 这是潜在点条件近似，不是真实重复值区间条件分布；固定缺陷等于源值比“不增加”更严格。缺陷缺失的两款仍不可完整验收，不用插补值认证完整达标。
- 同时重算原OT+投影作为对照。检查alpha={0,0.25,0.5,0.75,1}；均使用最终坐标经G再评价，统一231维RMS；记录真正投影触发数，不能以“等于源值”的数量代替。
- v3.1四条冻结验收原样保留。v4候选验收：四项已观测缺陷非增且下限状态保留、陈化代理非增、启用后分类器得分>=0.5、到真实Tripel最近邻距离至少下降10%。分类器对每款源使用剔除该源后重拟合版本。v4不再把中心收缩20%作为主风格条件。
- 先按各方法首次达标alpha比较同一组源样本，报告成功/失败/不可验收、改变量和群体离散度。条件OT只有在完整达标数不低于原法、共同达标样本平均改变量更低，且同alpha下离散度不低于原法85%时才优先为主方法。若失败保留原法。规则属于新v4开发标准，不追溯改变旧结论。

## 冻结后的依赖工作

最终Q1确定后才重建相对评分锚点、支持度及Q3感官画像。Q2须对最终完整预测函数重跑100次bootstrap及置换，并保留模块联合置换；不做knockoff。保形区间采用正式split/CV+构造，不能把普通OOF残差分位数直接宣称覆盖保证。ALE限关键维度并标注密度与阈值，学习曲线只改变训练子集。工艺建议定位为待验证方向。附录与动态门控不阻塞本轮核心方案冻结。
